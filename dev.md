# Dev

### 1. Run locally

```bash
docker compose up
```

→ http://localhost:8080

### 2. Push

```bash
git add -A && git commit -m "update info" && git push origin main
```

### 3. Check live

→ https://kangqi-ni.github.io

Deploy takes ~2 min: [Actions](https://github.com/kangqi-ni/kangqi-ni.github.io/actions)
